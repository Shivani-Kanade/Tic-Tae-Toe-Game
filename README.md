# 🎮 Tic Tac Toe

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**.

## ✨ Features

* 👥 Two-player gameplay
* 🏆 Automatic win detection
* 🤝 Draw detection
* 🔄 Restart/Reset game option
* 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🎯 How to Play

1. Player 1 plays with **O**.
2. Player 2 plays with **X**.
3. Players take turns selecting an empty cell.
4. The first player to get three symbols in a row, column, or diagonal wins.
5. If all cells are filled without a winner, the game is a draw.
